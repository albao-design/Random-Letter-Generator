# Random Letter Generator

Type a message (up to 30 characters) and every letter is set in a different, randomly chosen Google Font.

- **Text effects:** blur, spacing, stretch, size, stroke and tilt
- **Animations:** bounce, chaos, float, pulse, typewriter and shuffle
- **Export:** high-resolution PNG (with optional transparent background) or a square 1080 × 1080 MP4 video, about 8 seconds long, ready for Instagram, TikTok, X and LinkedIn

Works in any modern browser on desktop and mobile.
